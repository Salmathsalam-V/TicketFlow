# TicketFlow Backend
# Ticket Management System

A full-stack Ticket Management System built using Django REST Framework and React.

## Tech Stack

### Backend

* Python
* Django
* Django REST Framework
* SQLite

### Frontend

* React
* Vite
* Material UI
* Axios

## Features

* User authentication
* Ticket creation
* Ticket listing
* Ticket filtering
* Ticket updating
* Ticket deletion
* Admin ticket management
* Ticket assignment
* Role-based permissions
